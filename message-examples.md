# Broadcast Message Templates — Kamilight Global Logistics

Copy-paste these directly into Telegram broadcast commands.

## General Tips

- Keep messages under 500 characters for best readability on mobile
- Never use ALL CAPS — it reads as shouting
- Always include a clear call-to-action (reply, call, book)
- Personalization of name can be added when the automation supports it (Phase 4)
