# Going live: WhatsApp number + AI assistant

Do these in order. Nothing here can send a real message until step 5, and the AI stays off until step 8.
Meta occasionally renames screens; the names below are the ones in use at the time of writing.

## What you need

- A Meta (Facebook) login that will own KGL's business assets, ideally a KGL director's, not a personal account of the consultant.
- The new KGL SIM, able to receive an SMS or call for the verification code.
- The number **must not already be registered on the WhatsApp or WhatsApp Business app.** If it is, delete that WhatsApp account first. Once the number is on the Cloud API, customers still message it as normal; the team replies from the dashboard **Inbox**.
- An Anthropic API key (console.anthropic.com), on an account KGL controls, with a small prepaid balance.

## 1. Meta business portfolio (business.facebook.com)

1. Create or open KGL's business portfolio. Business Settings → Business info: legal name, address, website, phone.
2. Start **Business verification** (Security centre). Approval can take a few days and is needed to lift the messaging limits; begin it now.

## 2. App (developers.facebook.com)

1. My Apps → Create app → type **Business** → connect it to KGL's business portfolio.
2. Add the **WhatsApp** product. Under WhatsApp → API setup, Meta gives a free test number and a temporary 24-hour token. Use these only for a first trial.
3. App settings → Basic: copy the **App secret**. This becomes `WA_APP_SECRET`.

## 3. Add KGL's real number

WhatsApp → API setup → **Add phone number**: business display name (use "Kamilight Global Logistics"), category (Logistics), the SIM's number, then the SMS/voice code. The display name goes through a short review. Copy the **Phone number ID** (not the number itself). This becomes `WA_PHONE_NUMBER_ID`.

## 4. A permanent token (the 24-hour one is not enough)

Business Settings → Users → **System users** → Add (role: Admin) → Add assets: the app (full control) and the WhatsApp account (full control) → **Generate token** → pick the app → tick `whatsapp_business_messaging` and `whatsapp_business_management` → set expiry **Never**. Copy it once. This becomes `WA_TOKEN`.

## 5. Settings in Render (kgl-crm → Environment)

Type these straight into Render; never paste them into chat, email or the repository.

| Setting | Value |
|---|---|
| `WA_APP_SECRET` | the App secret from step 2. **Set this first.** |
| `WA_PHONE_NUMBER_ID` | from step 3 |
| `WA_VERIFY_TOKEN` | already generated by Render; read it from the same page |
| `WA_TOKEN` | from step 4. Set it **last**: it switches the system out of test mode |
| `ANTHROPIC_API_KEY` | from the Anthropic console (used in step 8) |

Render redeploys by itself. The dashboard's "Test mode" banner disappears once `WA_TOKEN` is set.

## 6. Connect the webhook

Meta app → WhatsApp → **Configuration** → Webhook: Callback URL `https://kgl-crm.onrender.com/api/webhooks/whatsapp`, Verify token = `WA_VERIFY_TOKEN`. Click Verify and save, then **subscribe to the `messages` field**.
Test: from any phone, message the KGL number. The conversation must appear under **Inbox** within seconds.

## 7. Message templates (needed for campaigns, not for replies)

WhatsApp Manager → Message templates. Create and submit:

- a **Marketing** template for win-back and promotions (for example `winback_offer`, one variable `{{1}}` = first name);
- a **Utility** template for quote follow-up and welcome.

Approval is usually minutes to a day. Then enter the approved names under Automations → "WhatsApp template", or in the campaign builder.
Replies inside 24 hours of a customer's message (the AI's and staff's) need no template.

## 8. Switch the AI on

Dashboard → **AI assistant**:

1. Replace the starter outline with KGL's real facts: services, how to book, office hours, payment, anything it may quote word for word. **It only states what is written here.**
2. Use "Try it as a customer" with the questions customers really ask (price, tracking, complaints, a voice-note scenario). Check it hands over when it should.
3. Switch it on. Watch the Inbox for the first day; staff can pause the AI on any chat or take over by simply replying.

## 9. Before real customers

- [ ] Render plan upgraded to **Starter ($7)**. A sleeping free instance answers a customer's first message about a minute late, which defeats the point of an instant assistant.
- [ ] Marketing consent: no customer is marked as agreed to offers. Win-back and promotions only reach customers with consent; staff can record it on a profile, or import a list with the consent box ticked.
- [ ] 19 customers still need a valid number (fix list from the import).
- [ ] Staff have personal logins (Team page); the admin password has been changed.
- [ ] Old secrets rotated (Supabase secret key, database password, Render API keys).

## What the AI can and cannot do

Can: answer from the knowledge you wrote, ask for route / goods / weight, save details onto the customer record, log quote requests, plan follow-ups, hand over to a person. Writes a note on the customer's timeline every time it changes something.

Cannot: invent prices, change a customer's status, record marketing consent, message anyone who replied STOP, reply after 24 hours of silence, or read voice notes and images (those go straight to staff). It stops after the configured number of replies per customer per day and hands over.
